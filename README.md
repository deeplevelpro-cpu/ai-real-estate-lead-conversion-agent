# AI Real Estate Lead Conversion Agent

An AI-powered lead qualification and follow-up agent that helps real estate businesses convert inquiries into qualified appointments.

## Vision

Reduce lost leads by responding instantly, understanding buyer intent, qualifying prospects, and helping agents focus on high-value conversations.

## MVP Goal

The first version focuses on:

- AI lead qualification
- Automated follow-up
- Lead scoring
- Agent dashboard
- Website chat integration

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- AI APIs
